# Instagram Clone Using C++
This project will be a photo-sharing web app modeleed after Instagram's core experience. The backend will be written in C++ using lightweight HTTP framework, and the frontend will be vanilla HTML, CSS, and JavaScript communicating with the backend via a REST API.
The main purpose of this project is to become proficient in C++ and brush up on front end development.

**Topics that this project will cover:**
- HTTP servers
- REST API design
- Relational Databases
- Authentication
- File Uploads
- Frontend-backend Communication
- Deployment Fundamentals

## Scope
- user registration and login (with hashed passwords and session tokens)
- profile pages with avatar, bio, and a grid of posts
- photo upload with server side storage
- home feed showing posts from followed users, sorted by recency
- like and unlike posts
- comment on posts
- follow and unfollow users
- basic search for users by username
